Built a centralized **Jenkins CI/CD environment** to monitor and orchestrate deployments across multiple application repositories and servers.

The setup includes:

### 🌐 Hybrid VPS & Self-Hosted Infrastructure

Designed a hybrid infrastructure where a **VPS acts as the public ingress gateway** while applications remain hosted on a private Linux server.

The architecture uses:

- Cloudflare DNS
- VPS with public static IP
- Nginx Proxy Manager
- NetBird / WireGuard private networking
- Ubuntu-based application server
- Docker
- Laravel
- MinIO object storage

```text
Internet
   │
   ▼
Cloudflare DNS
   │
   ▼
Public VPS
   │
Nginx Proxy Manager
   │
   ▼
Private VPN Network
   │
   ▼
Ubuntu Server
   │
   ├── Laravel Applications
   ├── MinIO
   └── Other Services
```

This architecture was also used to support large application uploads while keeping the main application infrastructure private.

Migrated multiple **PHP, Laravel, and CodeIgniter applications** from a Windows-based environment to an Ubuntu Server environment.
